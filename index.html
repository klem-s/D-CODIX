DÉCODIX

Un code à 5 chiffres se cache dans le coffre. Chaque essai révèle la position des chiffres — et quatre indices globaux de déduction.

Bien placé Présent, mal placé Absent Σ / parité / écart / doublons

Code secret régénéré chaque jour à minuit (UTC). Le mode rapide ne garde ni score ni classement.
